## 🎮 Overview

**World Recipe** is inspired by games like Animal Crossing but focuses on a culinary adventure. Players:

1. **Choose a Dish** → Select from featured dishes (Ramen, Tagine, Tacos, Pho, etc.)
2. **Explore an AI-Generated World** → Each dish creates unique regions with themed environments
3. **Befriend NPCs** → Meet AI-generated characters with personalities, schedules, and quests
4. **Gather Ingredients** → Collect items through trading, harvesting, fishing, or crafting
5. **Complete Quests** → Follow quest chains that teach cooking techniques
6. **Cook the Dish** → Master mini-games (stir, chop, toast) to complete cooking steps

The entire world—regions, NPCs, quests, ingredients—is procedurally generated by AI based on the selected dish.

### Core Concepts

#### 1. WorldRecipe
The main generated object containing everything about a game world:
- **Dish** - The target recipe (name, difficulty, story hook)
- **Regions** - 2-5 themed areas with maps, POIs, palettes
- **NPC Roster** - 8-20 characters with personalities & schedules
- **Quest Arcs** - 2-6 quest chains that unlock cooking steps
- **Ingredient Graph** - Dependency tree of ingredients

#### 2. Game Time
- 24 minutes real time = 1 in-game day
- 4 time phases: morning, day, evening, night
- NPCs follow schedules based on time
- Lighting adjusts automatically

#### 3. Relationship System
- NPCs have relationship levels (0-10)
- Higher levels unlock rewards, recipes, dialogue options
- Build relationships through conversations and quest completion

## 🤖 AI System

### World Generation Pipeline

When a player selects a dish, the following happens:

```
1. User selects "Tonkotsu Ramen"
           │
           ▼
2. POST /api/ai/world
   {
     dishPrompt: "Tonkotsu Ramen",
     seed: "unique-uuid",
     playerPrefs: { difficulty: "medium", regions: 3 }
   }
           │
           ▼
3. Check cache (inputHash → aiGenerations table)
           │
           ▼ (cache miss)
4. Build prompt with COZY_WORLD_SYSTEM_PROMPT
           │
           ▼
5. generateObject({
     model: gateway('openai/gpt-4o'),
     schema: worldRecipeSchema,
     temperature: 0.7
   })
           │
           ▼
6. Validate referential integrity
   - Do quest giver NPCs exist?
   - Do NPC schedule POIs exist?
   - Do ingredient regions exist?
           │
           ▼
7. Store in database & cache
           │
           ▼
8. Return WorldRecipe JSON
```

### AI Schemas (`lib/ai/schemas.ts`)

All AI outputs are validated with Zod schemas:

```typescript
// World Recipe - The main schema
export const worldRecipeSchema = z.object({
  worldId: z.string(),
  seed: z.string(),
  dish: dishSchema,
  regions: z.array(regionSpecSchema).min(2).max(5),
  ingredientGraph: ingredientGraphSchema,
  questArcs: z.array(questArcSchema).min(2).max(6),
  npcRoster: z.array(npcSchema).min(8).max(20),
  colorSystem: z.object({...}),
  startingInventory: z.array(itemStackSchema),
});
```

### System Prompts (`lib/ai/prompts.ts`)

Three main prompts:

| Prompt | Purpose | Model |
|--------|---------|-------|
| `COZY_WORLD_SYSTEM_PROMPT` | World generation | GPT-4o |
| `DIALOGUE_SYSTEM_PROMPT` | NPC conversations | GPT-4o-mini |
| `QUEST_RESOLUTION_PROMPT` | Quest completion logic | GPT-4o-mini |

#### Key prompt guidelines:
- **Tone**: Warm, welcoming, family-friendly
- **Cultural Respect**: Inspired by, not copying real cultures
- **Safety**: G-rated, no controversial content
- **Gameplay Balance**: Achievable quests, findable ingredients

### Dynamic Dialogue Generation

When talking to an NPC:

```typescript
POST /api/ai/npc/dialogue
{
  worldId: "uuid",
  npcId: "npc_chef_hana",
  context: {
    relationshipLevel: 5,
    activeQuests: ["quest_gather_basics"],
    lastTalkSummary: "Discussed broth preparation",
    currentTimeOfDay: "morning"
  }
}
```

The AI generates contextual dialogue based on:
- NPC personality & speaking style
- Current relationship level
- Active quest progress
- Time of day
- Previous conversations

## 🗄 State Management

### Six Zustand Stores

#### 1. GameStore (`lib/store/gameStore.ts`)
Manages global game state:

```typescript
interface GameState {
  // Status
  isPlaying: boolean;
  isPaused: boolean;
  isLoading: boolean;
  
  // Time system
  timeOfDay: 'morning' | 'day' | 'evening' | 'night';
  dayNumber: number;
  gameTimeSeconds: number;
  playTimeSeconds: number;
  
  // World reference
  world: WorldRecipe | null;
  currentRegionId: string | null;
  
  // UI state
  interactionPrompt: InteractionPrompt;
  dialogueState: DialogueState;
  showJournal: boolean;
  showCooking: boolean;
  showInventory: boolean;
}
```

**Time System Logic:**
- `DAY_LENGTH_SECONDS = 24 * 60` (24 real minutes = 1 game day)
- Time phases: 0-6min (morning), 6-12min (day), 12-18min (evening), 18-24min (night)

#### 2. PlayerStore (`lib/store/playerStore.ts`)
Manages player-specific data:

```typescript
interface PlayerState {
  // Position
  position: [number, number, number];
  rotation: number;
  isMoving: boolean;
  
  // Inventory
  inventory: ItemStack[];
  maxInventorySlots: number;  // 24 slots
  
  // Quests
  activeQuests: QuestChapter[];
  completedQuestIds: string[];
  
  // Relationships
  npcRelationships: Record<string, number>;  // 0-10 per NPC
  
  // Cooking
  completedCookingSteps: string[];
  unlockedTechniques: string[];
  
  // Stats
  stamina: number;
  maxStamina: number;
}
```

**Key Methods:**
- `addItem(item, quantity)` - Add to inventory (stacks automatically)
- `removeItem(itemId, quantity)` - Remove from inventory
- `acceptQuest(quest)` - Start a quest
- `updateObjective(questId, objectiveId)` - Mark objective complete
- `updateRelationship(npcId, delta)` - Change relationship (clamped 0-10)

#### 3. WorldStore (`lib/store/worldStore.ts`)
Manages world data and API calls:

```typescript
interface WorldState {
  world: WorldRecipe | null;
  isLoading: boolean;
  error: string | null;
  currentRegionId: string | null;
  
  // Helpers
  getNPC: (npcId: string) => NPC | undefined;
  getQuestArc: (arcId: string) => QuestArc | undefined;
  getRegion: (regionId: string) => RegionSpec | undefined;
  
  // Async
  loadWorld: (worldId: string) => Promise<void>;
  generateWorld: (dishPrompt: string, seed?: string) => Promise<WorldRecipe>;
}
```

#### 4. PortalStore (`lib/store/portalStore.ts`)
Manages portal navigation between the hub world and portal sub-boards:

```typescript
interface PortalState {
  isInPortal: boolean;
  currentPortalBoardId: string | null;
  currentPortalType: PortalType | null;
  isTransitioning: boolean;
  portalHistory: Array<{ portalBoardId: string; portalType: PortalType; hubPortalPoiId: string }>;

  enterPortal: (portalPoi: POI) => Promise<boolean>;
  returnToHub: () => Promise<boolean>;
  canAccessPortal: (portalPoi: POI) => boolean;
  getCurrentPortalBoard: () => PortalBoard | null;
}
```

**Key Behavior:**
- Kitchen portals require all dish ingredients to access
- Other portal types are always accessible
- Maintains navigation history for return trips
- Coordinates with `PortalTransition` for animated travel effects

#### 5. NotificationStore (`lib/store/notificationStore.ts`)
Manages in-game toast notifications:

```typescript
interface NotificationState {
  notifications: Notification[];
  maxNotifications: number;  // 5 max visible

  // Convenience methods
  showQuestAccepted: (questTitle: string) => void;
  showQuestCompleted: (questTitle: string) => void;
  showObjectiveCompleted: (description: string) => void;
  showItemCollected: (itemName: string, quantity?: number) => void;
  showRelationshipUp: (npcName: string) => void;
  showAutosave: () => void;
}
```

**Notification Types:** `info`, `success`, `warning`, `error`, `quest_accepted`, `quest_completed`, `objective_completed`, `item_collected`, `relationship_up`, `autosave`

#### 6. SaveStore (`lib/store/saveStore.ts`)
Handles game persistence and autosave:

```typescript
interface SaveState {
  saveId: string | null;
  lastSaveTime: number | null;
  isSaving: boolean;
  isLoading: boolean;
  autoSaveEnabled: boolean;

  saveGame: () => Promise<boolean>;
  loadGame: (saveId?: string) => Promise<boolean>;
  loadLatestSave: (worldId: string) => Promise<boolean>;
  startAutoSave: (intervalMs?: number) => void;  // Default: 60s
  stopAutoSave: () => void;
}
```

**Key Behavior:**
- Aggregates state from `playerStore`, `gameStore`, and `worldStore` into a single save payload
- Autosave runs every 60 seconds (only while playing and not paused)
- Restores full game state from save data including position, inventory, quests, relationships, and time

### Store Usage Patterns

```typescript
// In components - use selectors for performance
const timeOfDay = useGameStore((s) => s.timeOfDay);
const position = usePlayerStore((s) => s.position);
const world = useWorldStore((s) => s.world);

// Get actions
const addItem = usePlayerStore((s) => s.addItem);
const toggleJournal = useGameStore((s) => s.toggleJournal);

// Get computed helpers
```

## 💾 Database Schema

### Tables (`lib/db/schema.ts`)

```sql
-- Stores generated WorldRecipe objects
CREATE TABLE worlds (
  world_id TEXT PRIMARY KEY,
  seed TEXT NOT NULL,
  dish_name TEXT NOT NULL,
  model_version TEXT,
  prompt_version TEXT,
  world_json TEXT NOT NULL,  -- Full WorldRecipe JSON
  created_at INTEGER
);

-- Stores player progress
CREATE TABLE saves (
  save_id TEXT PRIMARY KEY,
  world_id TEXT REFERENCES worlds(world_id),
  slot_number INTEGER DEFAULT 1,
  player_name TEXT DEFAULT 'Chef',
  
  -- Position
  current_region_id TEXT NOT NULL,
  player_position_x INTEGER DEFAULT 0,  -- Stored as x100
  player_position_y INTEGER DEFAULT 0,
  player_position_z INTEGER DEFAULT 0,
  
  -- Time
  day_number INTEGER DEFAULT 1,
  time_of_day TEXT DEFAULT 'morning',
  play_time_seconds INTEGER DEFAULT 0,
  
  -- Progress (JSON columns)
  inventory_json TEXT DEFAULT '[]',
  completed_quests_json TEXT DEFAULT '[]',
  active_quests_json TEXT DEFAULT '[]',
  npc_relationships_json TEXT DEFAULT '{}',
  completed_cooking_steps_json TEXT DEFAULT '[]',
  
  created_at INTEGER,
  updated_at INTEGER
);

-- Event telemetry
CREATE TABLE events (
  event_id INTEGER PRIMARY KEY AUTOINCREMENT,
  world_id TEXT REFERENCES worlds(world_id),
  save_id TEXT REFERENCES saves(save_id),
  event_type TEXT NOT NULL,
  payload_json TEXT,
  created_at INTEGER
);

-- AI generation cache
CREATE TABLE ai_generations (
  generation_id TEXT PRIMARY KEY,
  world_id TEXT REFERENCES worlds(world_id),
  generation_type TEXT NOT NULL,  -- 'world', 'dialogue', 'quest'
  input_hash TEXT NOT NULL,       -- SHA256 of input for cache lookup
  output_json TEXT NOT NULL,
  model_used TEXT,
  tokens_used INTEGER,
  created_at INTEGER
);
```

## 🌐 API Routes

### `POST /api/ai/world` - Generate World

**Request:**
```json
{
  "dishPrompt": "Tonkotsu Ramen",
  "seed": "optional-seed",
  "playerPrefs": {
    "difficulty": "medium",
    "regions": 3,
    "dietaryRestrictions": ["vegetarian"]
  }
}
```

**Response:**
```json
{
  "worldId": "uuid",
  "world": { /* WorldRecipe object */ },
  "cached": false,
  "usage": { "totalTokens": 5000 }
}
```

### `GET /api/ai/world` - Load World

- `?worldId=<id>` - Get specific world
- No params - List recent worlds

### `POST /api/ai/npc/dialogue` - Generate Dialogue

**Request:**
```json
{
  "worldId": "uuid",
  "npcId": "npc_chef_hana",
  "context": {
    "relationshipLevel": 5,
    "activeQuests": ["quest_gather_basics"],
    "currentTimeOfDay": "morning"
  }
}
```

**Response:**
```json
{
  "dialogue": {
    "speaker": "Chef Hana",
    "text": "Good morning! Ready to learn some cooking secrets?",
    "emotion": "happy",
    "choices": [
      { "text": "Yes, teach me!", "effect": { "type": "relationship", "value": 1 } },
      { "text": "Maybe later" }
    ]
  }
}
```

### `POST /api/ai/quests/resolve` - Resolve Quest Action

**Request:**
```json
{
  "worldId": "uuid",
  "questId": "quest_gather_basics",
  "playerActionSummary": "Collected 2 fresh eggs from the farm",
  "saveId": "optional-save-id"
}
```

### `POST /api/save` - Save Game

**Request:**
```json
{
  "worldId": "uuid",
  "playerPosition": [10, 0.5, 5],
  "inventory": [...],
  "completedQuests": [...],
  "npcRelationships": {...},
  // ... all game state
}
```

### `GET /api/save` - Load Save

- `?saveId=<id>` - Get specific save
- `?worldId=<id>` - List saves for world
- No params - List all recent saves

### Canvas3D (`components/game/Canvas3D.tsx`)

```tsx

  <OrthographicCamera makeDefault zoom={50} position={[10, 10, 10]} />

```

**Key Features:**
- Orthographic camera (isometric-style view)
- Physics-based movement (Rapier)
- Time-of-day lighting system
- Procedural decorations (trees, rocks, flowers)

### PlayerController (`components/game/PlayerController.tsx`)

Handles player input and physics:

```typescript
// Keyboard input
const useKeyboard = () => {
  const keysRef = useRef({ forward, backward, left, right, interact });
  // W/↑, S/↓, A/←, D/→, E/Space
};

// Player physics
<RigidBody linearDamping={5}>
  <CapsuleCollider args={[0.3, 0.25]} />
  <PlayerVisual isMoving={isMoving} />
</RigidBody>
```

**Movement System:**
- WASD or Arrow keys to move
- Isometric diagonal movement normalized
- Smooth rotation to face movement direction
- Camera follows player smoothly

### PortalBoard (`components/game/PortalBoard.tsx`)

Renders portal sub-worlds — self-contained mini-maps that players travel to through portals in the hub:

- Builds a mini-region from `PortalBoard` data (terrain, NPC, ingredients, palette)
- Reuses `VoxelTerrain`, `NPCManager`, and `InteractableManager` components
- Handles NPC interaction (starts dialogue, updates talk objectives)
- Handles ingredient pickup (adds items to inventory)
- Only renders when the player is inside a portal (controlled by `portalStore`)

### Scene Decorations

Voxel-style props:
- `VoxelTree` - Multi-layer blocky trees
- `VoxelRock` - Dodecahedron rocks
- `VoxelFlower` - Colorful ground flowers

## 🎯 Game Mechanics

### Quest System

```
QuestArc (e.g., "The Foundation")
  └── QuestChapter (e.g., "Meet the Chef")
        ├── Objectives
        │   ├── talk: npc_chef_hana
        │   └── gather: ing_noodles x1
        ├── Rewards: [item_chopsticks]
        └── nextQuestId: "quest_gather_basics"
```

**Objective Types:**
- `gather` - Collect items
- `deliver` - Give items to NPC
- `talk` - Speak with NPC
- `craft` - Create item
- `cook-step` - Complete cooking mini-game

### Ingredient System

```
IngredientGraph
├── ingredients[]
│   ├── { id: "ing_noodles", gatherMethod: "trade" }
│   ├── { id: "ing_pork", gatherMethod: "trade" }
│   └── { id: "ing_broth", gatherMethod: "craft" }
└── dependencies[]
    └── { from: "ing_pork", to: "ing_broth", type: "requires" }
```

**Gather Methods:**
- `pickup` - Find on ground
- `harvest` - Collect from plants
- `fish` - Catch from water
- `trade` - Buy from NPCs
- `craft` - Create from other ingredients

### Portal System

Players navigate between the hub world and themed portal sub-boards:

```
Hub Region (main map)
├── Portal: Market   → MarketBoard (trade ingredients, talk to vendors)
├── Portal: Farm     → FarmBoard (harvest, gather)
├── Portal: Fishing  → FishingBoard (catch fish ingredients)
└── Portal: Kitchen  → KitchenBoard (final cooking — requires all ingredients)
```

**Flow:**
1. Player walks to a portal POI in the hub
2. `portalStore.canAccessPortal()` checks requirements (kitchen portal needs all ingredients)
3. `portalStore.enterPortal()` starts the transition
4. `PortalTransition` plays the fade-out / swirl / fade-in animation
5. `PortalBoard` renders the sub-world (terrain, NPC, ingredients)
6. Player can interact, collect items, talk to NPCs
7. `portalStore.returnToHub()` sends the player back to the hub portal location

### Save & Autosave System

Game progress is persisted via the `saveStore` and `/api/save` endpoint:

- **Manual save:** `saveStore.saveGame()` serializes all store state and POSTs to the server
- **Autosave:** Runs every 60 seconds while playing (configurable via `startAutoSave(intervalMs)`)
- **Load:** `loadGame(saveId)` or `loadLatestSave(worldId)` fetches and restores full state
- **Visual feedback:** `AutosaveIndicator` shows "Saving..." spinner and last save timestamp

### Time & Schedule System

| Time Phase | Real Duration | In-Game Time | NPC Activities |
|------------|---------------|--------------|----------------|
| Morning | 6 min | 6:00-12:00 | Markets open, fishing |
| Day | 6 min | 12:00-18:00 | Teaching, selling |
| Evening | 6 min | 18:00-24:00 | Preparing dinner |
| Night | 6 min | 0:00-6:00 | Resting, closed shops |

## 👨‍💻 Development Guide

### Adding a New UI Panel

1. Create component in `components/ui/`:
```tsx
export function MyPanel() {
  const showMyPanel = useGameStore((s) => s.showMyPanel);
  const toggleMyPanel = useGameStore((s) => s.toggleMyPanel);
  
  if (!showMyPanel) return null;
  
  return (
    <div className="fixed inset-0 z-40 ...">
      <Card>...</Card>
    </div>
  );
}
```

2. Add state to `gameStore.ts`:
```typescript
showMyPanel: false,
toggleMyPanel: () => set((s) => ({ showMyPanel: !s.showMyPanel })),
```

3. Import in `app/game/page.tsx`:
```tsx
<MyPanel />
```

### Adding a New Mini-Game

1. Create component in `CookingUI.tsx`:
```tsx
function MyMiniGame({ onComplete }: { onComplete: (success: boolean) => void }) {
  // Game logic
  return <div>...</div>;
}
```

2. Add to `CookingStep.miniGameType`:
```typescript
miniGameType: 'stir' | 'chop' | 'toast' | 'myNewGame';
```

3. Render in `CookingUI`:
```tsx
{activeMiniGame.type === 'myNewGame' && (
  <MyMiniGame onComplete={handleMiniGameComplete} />
)}
```

2. Add schema validation in `lib/ai/schemas.ts` if needed
